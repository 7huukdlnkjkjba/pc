# ⚡ 禁忌秘典：Hanime1 次元突破自动化神器 ⚡

> **“我不是在写爬虫，我是在命令浏览器！”**

欢迎来到这个用 **Playwright** 锻造、专治各种“防采集不服”的赛博兵器库。本项目并非普通的网页打开工具，而是一次对浏览器底层机制的**降维打击**。我们直接劫持 Microsoft Edge 的内核，强行征召 NDM（Neat Download Manager）作为我们的先锋炮灰，只为在那个名为 Hanime1 的异次元战场，撕开一道数据洪流的缺口。

---

## 🚀 极速部署（凡人的步骤）

1.  掠夺依赖：
    ```bash
    pip install playwright
    playwright install msedge
    ```
2.  无需配置环境变量，无需登坛作法，直接运行：
    ```bash
    python hanime1.py
    ```
3.  当浏览器降临在你面前时，请像神明一样从容地点击、播放，最后在终端按下 **Enter** 终结这一切。

## 🧠 禁咒级核心奥义（骇客降维打击实录）

本项目藏匿了四大**对网站特攻**法则，每一行代码都是对反爬机制的无情嘲讽：

### 1. 🔥 抹除“自动化原罪”——让网站跪拜真实之躯
所有浏览器在自动化启动时，灵魂上都会被刻下 `navigator.webdriver = true` 的**原罪烙印**。我们做了什么？
- 使用 **`ignore_default_args=['--enable-automation']`** 直接撕碎了官方的身份铭牌。
- 祭出 **`--disable-blink-features=AutomationControlled`**，从 Chromium 内核的最底层篡改特征。
- **最终效果**：在 Hanime1 的服务器看来，我们不过是路过的亿万普通用户之一。它猜不到，也看不清，凝视它的是一双来自自动化深渊的冰冷瞳孔。

### 2. 💀 本地扩展“夺舍术”——无需商店，强行注入灵魂
你以为扩展只能从 Chrome Web Store 下载？太天真了。
- 我们利用 **`--load-extension`** 和 **`--disable-extensions-except`** 双剑合璧，直接跨过官方商店的腐朽城墙，**硬生生将本地磁盘上的 NDM 文件夹塞进了浏览器的内存空间**。
- 这一招俗称**“离线夺舍”**，让 NDM 扩展在浏览器启动的 0.01 秒内就被彻底唤醒，潜伏在浏览器的肌体之中，随时准备拦截所有视频流请求。

### 3. 🧬 时空冻结术（持久化上下文）
我们抛弃了无状态的普通窗口，选用了 **`launch_persistent_context`** 这一禁忌之术。
- 所有的 Cookies、LocalStorage、甚至 NDM 的未完成任务，都会被封印在 `ndm_profile` 这个异次元口袋中。
- **哪怕宇宙坍缩、程序崩溃**，只要再次启动脚本，你的登录态和下载队列就会瞬间重塑，仿佛时间从未流逝。

### 4. 🛸 人机融合の界面裂隙
我们没有使用愚蠢的 `time.sleep()`，而是采用了 **`input("按 Enter...")`** 这种神性挂起操作。
- 它在全自动的钢铁洪流中，硬生生撕开了一道**人为干预的深渊裂缝**。
- 你可以在浏览器完全模拟人类行为（滚动、悬停、点击）时，手动介入；当你玩弄够了，再施施然敲下回车，程序才会心满意足地含笑九泉（关闭）。
