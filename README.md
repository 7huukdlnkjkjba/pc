欢迎来到这个用 **Playwright** 锻造、专治各种“防采集不服”的赛博兵器库。本项目并非普通的网页打开工具，而是一次对浏览器底层机制的**降维打击**。我们直接劫持 Microsoft Edge 的内核，强行征召 NDM（Neat Download Manager）作为我们的先锋炮灰，只为在那个名为 Hanime1 的异次元战场，撕开一道数据洪流的缺口。

## 🚀 极速部署（凡人的步骤）

1.  掠夺依赖：
    ```bash
    pip install playwright
    playwright install msedge
    ```
2.  无需配置环境变量，无需登坛作法，直接运行：
    ```bash
    python hanime1.py
    ```
3.  当浏览器降临在你面前时，请像神明一样从容地点击、播放，最后在终端按下 **Enter** 终结这一切。

## 🧠 禁咒级核心奥义（骇客降维打击实录）

本项目藏匿了四大**对网站特攻**法则，每一行代码都是对反爬机制的无情嘲讽：

### 1. 🔥 抹除“自动化原罪”——让网站跪拜真实之躯
所有浏览器在自动化启动时，灵魂上都会被刻下 `navigator.webdriver = true` 的**原罪烙印**。我们做了什么？
- 使用 **`ignore_default_args=['--enable-automation']`** 直接撕碎了官方的身份铭牌。
- 祭出 **`--disable-blink-features=AutomationControlled`**，从 Chromium 内核的最底层篡改特征。
- **最终效果**：在 Hanime1 的服务器看来，我们不过是路过的亿万普通用户之一。它猜不到，也看不清，凝视它的是一双来自自动化深渊的冰冷瞳孔。

### 2. 💀 本地扩展“夺舍术”——无需商店，强行注入灵魂
你以为扩展只能从 Chrome Web Store 下载？太天真了。
- 我们利用 **`--load-extension`** 和 **`--disable-extensions-except`** 双剑合璧，直接跨过官方商店的腐朽城墙，**硬生生将本地磁盘上的 NDM 文件夹塞进了浏览器的内存空间**。
- 这一招俗称**“离线夺舍”**，让 NDM 扩展在浏览器启动的 0.01 秒内就被彻底唤醒，潜伏在浏览器的肌体之中，随时准备拦截所有视频流请求。

### 3. 🧬 时空冻结术（持久化上下文）
我们抛弃了无状态的普通窗口，选用了 **`launch_persistent_context`** 这一禁忌之术。
- 所有的 Cookies、LocalStorage、甚至 NDM 的未完成任务，都会被封印在 `ndm_profile` 这个异次元口袋中。
- **哪怕宇宙坍缩、程序崩溃**，只要再次启动脚本，你的登录态和下载队列就会瞬间重塑，仿佛时间从未流逝。

### 4. 🛸 人机融合の界面裂隙
我们没有使用愚蠢的 `time.sleep()`，而是采用了 **`input("按 Enter...")`** 这种神性挂起操作。
- 它在全自动的钢铁洪流中，硬生生撕开了一道**人为干预的深渊裂缝**。
- 你可以在浏览器完全模拟人类行为（滚动、悬停、点击）时，手动介入；当你玩弄够了，再施施然敲下回车，程序才会心满意足地含笑九泉（关闭）。

# 进阶攻略：让这套工具适配你的装备

## 核心思路

这脚本的本质就一句话：**指定一个浏览器 → 塞进去一个下载器扩展 → 打开目标网站**。

所以你想换浏览器、换下载器，只需要改两个东西：

1. **浏览器引擎**（用哪个浏览器）
2. **扩展路径**（塞哪个下载器进去）

其他全是套路，复制粘贴的活。

---

## 攻略一：从 Edge 换到 Chrome

Edge 和 Chrome 内核一样，都是 Chromium，所以脚本里只需要改一个词：

`channel='msedge'` → `channel='chrome'`

然后扩展路径从 Edge 的文件夹换成 Chrome 的文件夹。Chrome 的扩展藏在：

`C:\Users\你的用户名\AppData\Local\Google\Chrome\User Data\Default\Extensions\`

进去找到 NDM 的文件夹，把路径抄出来替换掉就行。

**耗时：2分钟。**

---

## 攻略二：从 NDM 换到 IDM

IDM 的扩展不是从商店装的，是 IDM 安装时自带的。位置一般在：

`C:\Program Files (x86)\Internet Download Manager\BrowserExtensions\`

里面有个文件夹叫 `IDM Integration Module`，把 `NDM_EXT` 指向它就完了。

不过 IDM 有个特殊的地方：它的扩展在 Edge 商店里也有上架，如果你想用商店版，直接去 `edge://extensions/` 搜 IDM 安装，然后从本地找它的 ID 路径也行。

**耗时：3分钟。**

---

## 攻略三：从 NDM 换到 FDM

FDM 和 IDM 类似，扩展也在安装目录里：

`C:\Program Files\Free Download Manager\BrowserExtension`

指向这个文件夹，完事。

如果找不到，打开 FDM 的设置，里面有个"安装浏览器扩展"的按钮，点一下它会自动装，然后你再去扩展管理页面看 ID，搜一下就知道路径了。

**耗时：3分钟。**

---

## 攻略四：浏览器和下载器一起换

比如换成 Chrome + IDM：

1. `channel='chrome'`
2. `NDM_EXT` 改成 IDM 扩展的路径
3. `USER_DATA` 也改个新名字，比如 `idm_profile`，免得和之前的配置互相干扰

三步搞定。其他所有参数都不用动。

---

## 攻略五：不用扩展，纯浏览器

如果你压根不需要下载器，只想用脚本快速打开 hanime1：

直接把 `args` 里那两行带 `NDM_EXT` 的删掉，还有 `disable-extensions-except` 那行也删了。

脚本就变成一个纯粹的"一键开浏览器 + 打开网站"工具。

---

## 核心知识点（记住这两条就够了）

| 你想换什么 | 改哪里 |
|-----------|--------|
| 换浏览器 | 改 `channel` |
| 换下载器 | 改 `NDM_EXT` 路径 |
| 清空配置 | 删掉或换个 `USER_DATA` 目录 |

---

## 找不到扩展路径？终极办法

1. 打开浏览器，进入扩展管理页面（`edge://extensions/` 或 `chrome://extensions/`）
2. 打开"开发者模式"
3. 你会看到每个扩展的 ID（一串字母数字）
4. 在电脑里搜索这个 ID
5. 搜出来的文件夹就是你要的路径

**这招通吃所有 Chromium 浏览器、所有扩展。**

只需要改路径和 channel，其他的一行都不用动。
